# FC 27 Reward

Video → animazione FC Points → codice. Sito statico, pensato per il telefono.

## Cambiare codice e punti

In `script.js`, in cima:

```js
const CONFIG = {
  code: "FUT27-GOAT-2026",
  points: 5000,
};
```

Il video è `video.mp4`.

## Pubblicarlo su GitHub Pages

1. Crea un repository pubblico su GitHub (es. `fut27`).
2. Carica questi file nella radice: `index.html`, `style.css`, `script.js`, `video.mp4`.
3. Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
4. Dopo un minuto il sito è su `https://TUO-UTENTE.github.io/fut27/`: usa questo link per il QR code.
